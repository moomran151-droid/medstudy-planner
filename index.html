نربط التطبيق بحسابك ☁️

أول مرة بس هنجهّز الاتصال بقاعدة البيانات. محتاجين رابط مشروع Supabase والمفتاح العام (publishable أو anon)، مش كلمة مرور حسابك ولا أي مفتاح سري.

منين أجيب الرابط والمفتاح؟

من لوحة مشروع Supabase: Project Settings → API أو صفحة Connect. انسخ Project URL والمفتاح العام فقط. لا تشارك أبدًا كلمة مرور حسابك أو service_role/secret key.

قبل المزامنة، لازم تنشئ جدول قاعدة البيانات باستخدام ملف supabase_setup.sql المرفق بالمشروع.
